# ProFoot – Pronostics football

Site statique (un seul fichier `index.html`). Aucun serveur ni installation requis.

## Mettre en ligne sur GitHub Pages
1. Créez un dépôt GitHub (ex. `profoot`), en public.
2. Cliquez sur **Add file → Upload files**, puis glissez `index.html` et `README.md` (dézippés).
3. Validez avec **Commit changes**.
4. Allez dans **Settings → Pages**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
5. Après 1 à 2 minutes, le site est disponible sur `https://VOTRE-PSEUDO.github.io/profoot/`.
